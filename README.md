# 🎁 Old Free Items Supercell

Bienvenue sur le dépôt de mon ancien site web dédié aux **récompenses gratuites des jeux Supercell**. Ce site servait de répertoire centralisé pour retrouver facilement tous les liens de récupération d'items gratuits (pins, icônes, décorations, ressources) distribués par Supercell.

🌐 **Lien vers le site :** [Old-Free-Items-Supercell](https://evanrio.github.io/Old-Free-Items-Supercell/)

## 🎮 Jeux pris en charge

Le site est divisé en plusieurs sections, une pour chaque jeu majeur de l'univers Supercell :
* 🌵 **Brawl Stars** (`bs.html`)
* ⚔️ **Clash of Clans** (`coc.html`)
* 👑 **Clash Royale** (`cr.html`)
* 🧑‍🌾 **Hay Day** (`hd.html`)
* 👾 **mo.co** (`mo.html`)
* 👶 **Squad Busters** (`sq.html`)

## ✨ Fonctionnalités

* **Menu de navigation visuel** : Une page d'accueil (`index.html`) avec des tuiles claires pour choisir son jeu.
* **Cartes interactives** : Chaque item gratuit est présenté sur une carte styled comme celles du jeu. 
  * Un bouton d'information (le petit "i") permet de basculer entre l'image de l'objet et sa description (géré en Vanilla JS).
  * Un bouton "Prix/Récupérer" redirige directement vers le lien officiel de récompense.
* **Design thématique** : Chaque page de jeu utilise les fonds d'écran, les séparateurs et l'esthétique propre à son univers, imitant le style du *Supercell Store*.

## 🛠️ Technologies utilisées

* **HTML5** : Structure sémantique des pages et intégration des méta-tags (Open Graph/Twitter) pour un beau rendu lors du partage de liens.
* **CSS3** : Flexbox pour les grilles, positionnement absolu pour les boutons interactifs sur les cartes, et utilisation de la police *Lilita One* pour correspondre au style graphique de Supercell.
* **JavaScript** : Petits scripts légers intégrés directement dans les pages pour gérer le basculement (toggle) entre les images et les descriptions des items sans recharger la page.
